# Archivo histórico

Estos documentos se conservan por trazabilidad. No son la guía vigente de
instalación, despliegue ni desarrollo. Cuando un documento del archivo
contradiga a uno operativo, prevalece el operativo y el código actual.

| Documento | Motivo del archivo |
|---|---|
| `AUDITORIA-INTEGRAL.md` | Snapshot de auditoría del 5-oct-2026; la mayoría de hallazgos ya se corrigió. |
| `HISTORIAL-FIXES.md` | Bitácora de correcciones cerradas. |
| `backend-README-ALCANCE.md` | Descripción anterior a la integración real; el estado vigente está en `backend/README.md`. |
| `frontend-CHANGELOG.md` | Changelog de una etapa anterior; las rutas que cita ya no existen. |
| `ALINEACION-FRONTEND-BACKEND.md` | Contrato antiguo; no describe la API actual ni la autenticación. |
| `plan-versionado-android.md` | Plan aplicado en el Lote 8; no es una tarea pendiente. |
| `privacidad-auditoria.md` | Revisión estática del 19-oct-2026; útil como antecedente, no como norma vigente. |

Los manuales de `docs/manual-tecnico/` también son un snapshot histórico y se
mantienen en su ubicación original.
